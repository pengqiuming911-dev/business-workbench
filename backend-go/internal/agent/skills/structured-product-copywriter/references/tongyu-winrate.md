# 通毓终端取胜率流程

本文档说明 agent 的 `fetch_winrate` 工具如何通过通毓量化终端(`terminal.tongyu-quant.com`)的"结构化产品回测"页,自动获取一个结构化产品的**回测胜率**,用于填补文案里的胜率数据。胜率是文案标题/副标题的核心卖点,必须真实可复现,绝不能编。

## 何时用这个流程

agent 的 `fetch_winrate` 工具(chromedp 驱动通毓终端)走本流程。工具失败/无 `TONGYU` 凭证/遇验证码/站点不可达时,返回 `[胜率待补]` 占位,让用户手动提供——不要因为没法自动取就编一个数字。下方各节(凭证/登录/填表映射/跑分析/读取)描述工具内部执行的流程,供你理解工具在做什么;你只需把产品参数(structure_type + 各百分比 + current_price)传给 `fetch_winrate`,不用手动驱动浏览器。

## 凭证

**不要把账号密码写进技能文件或任何会被打包的文件里。** 凭证从以下来源读(按优先级):

1. 环境变量 `TONGYU_USER` / `TONGYU_PASS`
2. 本地文件 `~/.claude/tongyu-creds.json`(在技能目录之外,不会被 `.skill` 包打包),格式:
   ```json
   {"username": "...", "password": "..."}
   ```

都没有就问用户要,或退回 `[胜率待补]`。

## 登录

1. 打开 `https://terminal.tongyu-quant.com/#/login`。
2. 顶部"管理员登录"按钮会跳到管理员门户(`/userManagement/`),**不是**我们要的入口——别点它。用页面中央的账号密码框。
3. 填用户名、密码,点"登录账号/Login"。
4. 成功后 URL 跳到 `/#/`(主页)。若返回 422 且响应体是 `用户名或密码错误`——凭证错,问用户核对;**不要**反复重试(会触发风控)。
5. 若弹出**滑块验证码**("请完成下列验证后继续"):这是反自动化风控,不要尝试程序绕过。退回 `[胜率待补]`,让用户在自己浏览器手动跑一次把胜率告诉你。降低触发概率的办法:用干净的单次登录(别短时间反复点)、用持久化浏览器 profile、用逐字键盘输入而非瞬间 fill。

## 进入回测页

登录后导航到 `https://terminal.tongyu-quant.com/#/investmentAnalysis/InvestmentAnalysis`(标题"结构化产品回测")。左侧菜单"结构化产品回测"。

若页面正中弹出"快捷查询"对话框(输入标的代码那个),先点右上角 close 关掉——它会遮挡表单点击。

## 填表:产品参数 → 表单字段映射

这是最关键的一步。表单字段会随"结构类型"选择动态变化,所以**先选结构,再填数**。映射表(左侧是用户给的参数,右侧是表单字段):

| 产品参数 | 表单字段 | 说明 |
|---|---|---|
| 结构类型 | 结构类型 → 组合结构类型 | 基础结构单选(DCN/经典/凤凰/早利/蝶变),叠加条款多选(降敲结构/降落伞结构/欧式结构等)。按产品勾选 |
| 标的 | 挂钩标的 | 搜索框输代码或名称;代码可用 `fetch_quote` 工具的标的映射(中证1000=000852.SH, 沪深300=000300.SH, 中证500=000905.SH, 创业板指=399006.SH 等) |
| 期限 | 期限(月) | 如 36 |
| 锁定期 | 有无锁定期 → 有锁定期,再填"锁定期(月)" | 如 3。选"有锁定期"后会多出锁定期月数字段 |
| 期初敲出线 | 首次观察敲出价(%) | 如 101。**选了降敲结构后才会出现此字段** |
| 降敲 | 敲出价递减步长(%) | 如 0.5(每月)。**选了降敲结构后才会出现** |
| 降落伞 | 期末障碍价(%) | 如 60。**选了降落伞结构后才会出现**(DCN 下叫"期末障碍价") |
| 派息线 | 派息障碍价(%) | 如 78。DCN 下出现 |
| 费后派息 | 每月或有派息(%) | 如 1.39。DCN 下出现 |
| 是否追保 | 是否追保 → 不追保/追保 | 单选 |
| 保证金 | 保证金水平(%) | 见下方"保证金坑" |
| 回测区间 | 回测区间 开始/结束日期 | 默认 2016-06-26 ~ 2026-06-25,通常用默认 |
| — | 价格区间 / PE区间 | 默认"全部",不动 |
| — | 开仓频率 | 默认"每日(交易日)",不动 |
| — | 敲出观察频率 | 默认"每月",DCN 下通常 disabled |

**末次观察敲出价**:选降敲后还会出现这个字段,它由"首次观察敲出价 − 步长 × 观察间隔数"自动联动,一般不用手填。若没自动联动,手填 = 首次 − 步长 ×(观察次数−1)。

**填数技巧**:`fetch_winrate` 工具(chromedp)内部按字段标签定位并填值(antd InputNumber 用 SetValue/SendKeys,不生效时回退逐字输入)。表单字段随结构选择动态增减,执行时每次交互后重新快照、按字段名定位当前 ref,不记死 ref。

## 保证金坑

选"不追保"后,保证金水平字段可能被**锁定**为站点默认值(如 40%),不可改。这是站点逻辑,不是 bug。**胜率由敲出/敲入结构(标的、期限、敲出价、敲入价、降敲、锁定期、回测区间)决定,保证金水平基本不影响胜率**——因为胜率算的是"合约能不能敲出/不敲入拿票息",与保证金杠杆无关。所以即便站点把保证金锁成 40%、产品实际是 50%,胜率数字仍可信;文案里保证金/杠杆仍按产品实际值写。

## 跑分析 & 读取

1. 点"立即分析"按钮。
2. 等 3~5 秒结果加载。
3. 读取结果区(标题"假设...买入一份该SNOWBALL合约"那块):
   - **胜率**(主要数字,如 98.14%)
   - 平均敲出时间(天)
   - 已完结合约共计(样本数,如 2361)
   - 盈利 / 亏损 笔数与概率(盈利概率 = 胜率)
4. 文案里引用胜率时,带上回测区间和样本数更有可信度,如"2016-06-26 至 2026-06-25 回测区间内 2361 个样本,胜率 98.14%"。

**胜率定义**:盈利概率 = 敲出(拿票息了结)+ 未敲入未敲出(持有到期拿票息);亏损 = 敲入未敲出。

## 字段会变怎么办

通毓终端是 Vue 单页应用,表单字段随结构选择动态增减、ref 每次交互后可能变。本文档给的是字段**语义映射**(哪个产品参数对应哪个表单字段),不是死的 ref 编号。执行时每次点击/填值后重新快照,按字段名(如"首次观察敲出价""期末障碍价")定位当前 ref,不要记旧 ref。这样 UI 改版也能跟上。
