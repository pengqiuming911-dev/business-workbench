# 飞书原生云文档推介材料模板

最终输出是飞书原生 `/docx/` 云文档，不是 Word 附件。用 `create_docx_material` 组装 manifest 并写入飞书。

## 标准章节顺序

每个标题都用 H2，严格按以下 11 节顺序：

1. 产品结构文字版（长版）
2. 产品结构文字版（短版）
3. 产品公告群通知
4. 稳定版接龙通知
5. 产品派息与敲出观察点位表图片
6. 产品胜率数据
7. 一页通
8. 管理人-基金业协会公示图
9. 产品-基金业协会公示图
10. 托管募集账户核对
11. 销售常见问题

## manifest 写法

`sections` 数组按顺序写入：

- `heading`：H2 标题。
- `body`：正文，支持多段文本。
- `params`：参数块。
- `image`：图片块，`path` 填截图工具返回的本地 path，`caption` 写图片说明。
- `link_list`：销售常见问题链接列表，每项 `{label,url}`。
- `separator`：可选，默认不需要。

示例：

```json
[
  {"type":"heading","text":"产品结构文字版（长版）"},
  {"type":"body","text":"【 月月派息·安全垫双重加厚｜中证1000 2倍降敲DCN】\n\n..."},
  {"type":"heading","text":"产品派息与敲出观察点位表图片"},
  {"type":"image","path":"public/poster-artifacts/product-card.png","caption":"产品派息与敲出观察点位表图片"},
  {"type":"heading","text":"销售常见问题"},
  {"type":"link_list","items":[{"label":"管理人相关常见问题","url":"https://..."}]}
]
```

## 章节内容规则

- 长版：推介文案 + 基础结构。标题必须在最前面。
- 短版：只写基础结构、打款日和入场时间。
- 产品公告群通知：暂时空。
- 稳定版接龙通知：暂时空。
- 产品派息与敲出观察点位表图片：插入 `screenshot_product_card` 返回的图片。
- 产品胜率数据：先写“回测时间从 YYYY年MM月DD日到 YYYY年MM月DD日，本产品胜率：XX%”，再插入胜率截图；没有截图时留占位。
- 一页通：留占位待手工补充。
- 管理人-基金业协会公示图：先写管理人名称和 AMAC 详情页链接，再插入详情页截图。
- 产品-基金业协会公示图：先写产品名称和 AMAC 详情页链接，再插入详情页截图。
- 托管募集账户核对：只展示账户、账号、银行，并补充托管户核验方式链接或说明。
- 销售常见问题：只放用户指定的飞书链接列表。

## 注意

图片要用元素内容截图或工具返回图，不要截浏览器整页视口。`create_docx_material` 会按图片原始比例写入飞书图片块。
